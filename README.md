# Hotell Fjällheim
Webbplats för Hotell Fjällheim 2.0 - ett hotell i Dalarna, Sverige. 
Byggt med React 19, TypeScript, Vite och Tailwind CSS V4

Krav
Kräver node.js 20 eller senare för att köras

# Sidor
Routing sköts av React-router-dom i Src/app.tsx

# Projectstruktr
Grundmallen satte upp React, Vite med HMR och Oxlint regler.
